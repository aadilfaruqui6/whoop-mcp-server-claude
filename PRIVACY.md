# Privacy Policy

Last updated: 2026-10-26

This is a personal-use application. It is run only by its owner, Aadil Faruqui, on their own computer.

- **What it accesses:** the owner's own WHOOP data (recovery, sleep, cycles, workouts, profile and body measurements), using the scopes the owner approves on WHOOP's consent page.
- **Where data goes:** requests go directly from the owner's computer to WHOOP's API. WHOOP data is passed only to the AI assistant the owner chooses to connect, in the owner's own session, to support their training decisions.
- **Storage:** OAuth tokens are stored in a file on the owner's computer that only the owner can read (`~/.config/whoop-mcp/tokens.json`). The app does not run a server, keep a database, or store WHOOP data anywhere else.
- **Sharing and selling:** none. No data is shared with, or sold to, third parties, and no other users are supported.
- **Revoking access:** the owner can revoke access at any time in the WHOOP app settings or the WHOOP developer dashboard, and can delete the token file.
